# أصوات المنيو

نغمات موسيقية ناعمة (طابع كاليمبا/ماريمبا) مولّدة بالكود من `generate-notes.py`، يعني ملكنا بالكامل وبدون أي رخصة خارجية.
كلها على السلّم الخماسي (دو ري مي صول لا) عشان أي نغمتين ورا بعض تطلع متناغمة. mono، 80kbps، المجموع حوالي 130KB، وبتتحمّل بس بعد أول لمسة.

| الملف | النغمات | وين بينسمع |
| --- | --- | --- |
| tap-1..5.mp3 | نغمة وحدة، خمس درجات مختلفة | لمسة: الأقسام، المزاج، الرئيسية، وزيادة/نقص الكمية |
| toggle-on / toggle-off | نغمتين صاعدة / نازلة | اختيار/إلغاء إضافة، مفضلة، حجم، لغة |
| open / close | صول-دو / دو-صول | فتح وسكر النوافذ |
| select | مي-لا | فتح السلة، "اختر لي" |
| add | دو-مي-صول (أربيج صاعد) | إضافة صنف للسلة |
| remove | صول-مي | حذف صنف من السلة |
| chime | دو-صول-مي عالي | شاشة الترحيب، تنبيه الويتر |
| celebrate | دو-مي-صول-دو-مي (خمس نغمات صاعدة) | تأكيد الطلب، الطلب جاهز |

لتغيير النغمات: عدّل `generate-notes.py` وشغّله من نفس المجلد (`python3 generate-notes.py`، يحتاج numpy و ffmpeg).
