# OLV Online Menu

نسخة أولية لمنيو OLV ثنائية اللغة.

## تشغيل
افتح `index.html` عبر استضافة ويب أو local web server. لأن المتصفح يمنع fetch من file:// في بعض الحالات، يفضل تشغيل:
`python -m http.server 8000`
ثم افتح:
`http://localhost:8000`

## الإدارة
`admin.html` نموذج أولي لواجهة إدارة الأصناف والأسعار.
في نسخة الإنتاج سيتم نقل البيانات إلى قاعدة بيانات وربط لوحة الإدارة بحفظ مباشر.

## ملاحظات
- الأسعار أولية ومقترحة للسوق الأردني وليست أسعارًا نهائية.
- شعار OLV موجود في `assets/olv-logo.png`.
- الطلب حاليًا تجريبي ولا يرسل إلى المطبخ؛ نقطة التكامل التالية هي API الطلبات/WhatsApp أو نظام POS.
